# example-task1 — iOS приложение с хранением данных в .plist на языке Swift

## Описание

Чтение данных из Data.plist и отображение их на экране. Демонстрация работы с NSDictionary и Bundle.

## Технологии

- Xcode 16+ / iOS 17+
- Swift, .plist

## Установка

1. Открыть `*.xcodeproj` в Xcode
2. Выбрать симулятор (iPhone 16+)
3. Нажать ▶️ Run
