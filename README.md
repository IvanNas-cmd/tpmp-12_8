# example-task6 — iOS приложение с использованием Core Data на языке Swift

## Описание

CRUD операции: добавление и удаление студентов. Таблица UITableView + CoreData. Автоматическая загрузка данных при старте.

## Технологии

- Xcode 16+ / iOS 17+
- Swift, CoreData, UITableView

## Установка

1. Открыть `*.xcodeproj` в Xcode
2. Выбрать симулятор (iPhone 16+)
3. Нажать ▶️ Run
