# example-task4 — iOS приложение с функцией определения местоположения по карте на языке Swift

## Описание

MKMapView с отображением текущего местоположения пользователя. Аннотация на карте с центрированием региона.

## Технологии

- Xcode 16+ / iOS 17+
- Swift, MapKit, CoreLocation

## Установка

1. Открыть `*.xcodeproj` в Xcode
2. Выбрать симулятор (iPhone 16+)
3. Нажать ▶️ Run
