# example-task2 — Приложение с авторизацией и хранением данных в NSUserDefaults на языке Swift

## Описание

Форма логина/регистрации с SegmentedControl. Хранение паролей в NSUserDefaults. Switch для согласия с правилами.

## Технологии

- Xcode 16+ / iOS 17+
- Swift, NSUserDefaults

## Установка

1. Открыть `*.xcodeproj` в Xcode
2. Выбрать симулятор (iPhone 16+)
3. Нажать ▶️ Run
