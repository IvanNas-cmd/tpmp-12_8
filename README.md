# feature-task2-2 — Интерактивная карта факультетов и общежитий БГУ

## Описание

Вариант 17. MapKit + CoreLocation + CoreData. LongPress на районе → список зданий БГУ в этом районе. Прогноз погоды через OpenWeatherMap. Локализация на 3 языка (русский, английский, польский). MVC архитектура.

## Технологии

- Xcode 16+ / iOS 17+
- Swift, MapKit, CoreLocation, CoreData, OpenWeatherMap, 3 языка (RU/EN/PL)

## Установка

1. Открыть `*.xcodeproj` в Xcode
2. Выбрать симулятор (iPhone 16+)
3. Нажать ▶️ Run
