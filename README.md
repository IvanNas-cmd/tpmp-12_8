# example-task5 — Система бронирования билетов на Objective-C

## Описание

Бронирование авиабилетов с использованием CoreData и MapKit. LongPress на карте → reverse geocoding → определение города. Данные хранятся в SQLite через CoreData.

## Технологии

- Xcode 16+ / iOS 17+
- Objective-C, CoreData, MapKit, CoreLocation

## Установка

1. Открыть `*.xcodeproj` в Xcode
2. Выбрать симулятор (iPhone 16+)
3. Нажать ▶️ Run
