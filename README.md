# feature-task2-1 — Приложение «Минская область» — хранение в NSUserDefaults и .plist

## Описание

Вариант 17. Экран авторизации → UICollectionView с 12 городами Минской области → детальный экран с картой. Данные из .plist. Локализация на 3 языка (русский, английский, польский). MVC архитектура.

## Технологии

- Xcode 16+ / iOS 17+
- Swift, NSUserDefaults, .plist, UICollectionView, 3 языка (RU/EN/PL)

## Установка

1. Открыть `*.xcodeproj` в Xcode
2. Выбрать симулятор (iPhone 16+)
3. Нажать ▶️ Run
