# example-task7 — iOS приложение прогноза погоды на языке Swift

## Описание

Получение данных через OpenWeatherMap API. URLSession для сетевых запросов. JSON парсинг. Поиск по городу и по текущей локации.

## Технологии

- Xcode 16+ / iOS 17+
- Swift, URLSession, CoreLocation, OpenWeatherMap

## Установка

1. Открыть `*.xcodeproj` в Xcode
2. Выбрать симулятор (iPhone 16+)
3. Нажать ▶️ Run
