# example-task3 — iOS приложение с функцией геолокации на языке Swift

## Описание

Определение текущего местоположения через CoreLocation. Отображение широты и долготы на экране.

## Технологии

- Xcode 16+ / iOS 17+
- Swift, CoreLocation

## Установка

1. Открыть `*.xcodeproj` в Xcode
2. Выбрать симулятор (iPhone 16+)
3. Нажать ▶️ Run
